# 设置页下拉滚动与开关对比度修复设计

## 背景

设置页圆角下拉改为 Radix Select 后出现三个问题：

1. Radix Select 的展开内容内部固定使用 `RemoveScroll`、焦点陷阱和外部指针锁定。打开下拉时页面不能滚动，桌面滚动条被移除，导致页面居中位置与底部胶囊发生横移；手机端也不能触控滚动。
2. 下拉动画同时包含位移和缩放。缩放围绕浮层定位原点发生，视觉上像从左上角向右下角展开，而不是纯纵向淡入。
3. Switch 关闭轨道与“进入章节时默认实时翻译”横条都使用 `bg-muted`，关闭时轨道边界融入父背景，只能清楚看到圆形滑块。

本轮修复只调整共享下拉的交互实现、下拉动画和共享 Switch 的关闭态对比度，不改变任何设置值、保存行为或页面布局。

## 下拉实现方案

共享 `Select` 组件的公开接口保持不变，底层由 Radix Select 改为 Radix DropdownMenu 的非模态单选菜单：

- 使用 `DropdownMenu.Root modal={false}`，避免页面滚动锁、滚动条移除、焦点陷阱和外部指针禁用。
- Trigger 继续使用当前 44px 高、16px 圆角、左右 16px 留白及旋转箭头。
- Content 继续通过 Portal 与 Popper 定位，保持与触发器等宽、16px 圆角、视口碰撞避让及高层级。
- 使用 RadioGroup 与 RadioItem 表达单选值，当前项继续显示浅色圆角背景和右侧勾选。
- 选择新值时调用现有 `onValueChange` 并关闭菜单；选择当前值也关闭菜单，但不产生无意义的数据变化。
- 组件继续支持受控 value、选项、disabled、className 和无障碍名称，设置页调用方无需改变。

不采用 CSS 或脚本抵消 Radix Select 的 `RemoveScroll`，因为其外部指针锁定和焦点陷阱仍会使桌面触控及手机滚动脆弱。也不使用 Popover 自行重做单选语义，以避免重复实现方向键和选中状态管理。

## 页面滚动行为

- 菜单打开前后，文档滚动条始终保留，页面可用宽度不变。
- 桌面鼠标滚轮、触控板与手机触控拖动均可继续滚动整页。
- 页面滚动期间菜单保持打开，Popper 根据触发器位置持续更新，使浮层跟随触发器移动。
- 页面滚动不是关闭条件。
- 选择选项、点击/轻点菜单外或按 Escape 时关闭。
- 鼠标在菜单外按下时沿用 Radix 的即时关闭行为。
- 手机端在菜单外触摸按下时阻止 Radix 的 `pointerdown` 自动关闭，改由随后的外部 `click` 关闭；触控拖动页面不会产生该 click，因此滑动不会被误判为轻点，菜单保持打开。
- 外部 click 处理使用触发器与浮层引用排除内部点击，并只在菜单打开期间注册，关闭时立即清理。
- 菜单关闭后焦点返回触发器；键盘可使用 Enter/Space 打开、方向键移动、Enter 选择、Escape 关闭。

## 动画

下拉浮层移除所有缩放和横向位移，只保留透明度与固定方向的纵向位移：

- 打开：`opacity: 0; translateY(-6px)` 到 `opacity: 1; translateY(0)`，约 150ms。
- 关闭：反向淡出并移动至 `translateY(-6px)`，约 150ms。
- 不再根据 `data-side` 设置不同位移变量。
- 即使 Popper 因空间不足将菜单放在触发器上方，动画仍从正上方向正下方进入，保持一致的视觉语言。
- Trigger 箭头旋转保持不变。
- `prefers-reduced-motion: reduce` 下完全禁用浮层位移/淡入动画与箭头旋转。

## Switch 关闭态

共享 Switch 组件只调整未选中轨道：

- 关闭轨道从 `bg-muted` 改为基于 `muted-foreground` 的半透明中性灰，使其与父级 `bg-muted` 横条形成稳定对比。
- 滑块继续使用主题背景色和阴影，完整轨道在深色、浅色主题中都清晰可辨。
- 开启轨道继续使用 `bg-primary`，位置、大小、动画、焦点和禁用状态不变。
- 当前项目只有设置页使用共享 Switch，因此调整范围明确；组件仍保持通用语义。

## 数据与范围边界

- 主题、阅读模式、翻页方向、源语言、翻译服务以及敏感字段操作的值和显示文字全部不变。
- 设置 draft、条件渲染、敏感值清空行为、提交载荷和服务器保存逻辑不变。
- 不修改阅读器阅读设置菜单、底部胶囊定位、Input、设置卡片或后端代码。
- 底部胶囊位置稳定通过消除下拉造成的页面宽度变化实现，不添加针对胶囊的补偿样式。

## 验证

### 滚动与布局

- 桌面打开下拉前后记录 `innerWidth`、文档客户区宽度、滚动条状态和底部胶囊矩形，数值保持不变。
- 菜单打开时通过鼠标滚轮滚动，页面滚动位置变化，菜单保持打开并与触发器同步移动。
- 手机视口中以触控序列拖动页面，页面正常滚动，菜单保持打开并不越出视口。
- 外部轻点关闭，选择关闭，Escape 关闭，关闭后焦点返回触发器。

### 视觉与无障碍

- 浮层动画计算样式不包含 `scale` 或横向 `translate`，上下定位都只使用 `translateY(-6px)`。
- reduced-motion 下动画为 `none` 且箭头不旋转。
- 普通与窄版下拉继续保持 16px 圆角、等宽浮层、选中背景与勾选。
- Switch 关闭轨道在深色和浅色截图中均能辨认完整胶囊，开启态仍使用主色。
- 键盘单选语义、当前项状态和无障碍名称正确。
