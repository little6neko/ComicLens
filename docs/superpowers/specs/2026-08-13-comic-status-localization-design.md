# 漫画详情状态中文化设计

## 背景与调查结果

ComicLens 目前在漫画详情页原样显示 Manga18fx 的 `Status` 元数据，因此用户会看到 `Ongoing`。Manga18fx 当前真实详情页的连载状态写作 `Ongoing`，完结状态写作 `Completed`；项目测试 fixture 中另有历史大小写变体 `OnGoing`。

从 Manga18fx 公开 sitemap 中的 4,022 部作品分层抽样检查 127 部，得到 108 部 `Ongoing` 和 19 部 `Completed`，未发现其他状态。站内搜索结果也未发现 `Hiatus`、`On Hold`、`Cancelled`、`Canceled`、`Dropped` 或 `Discontinued` 的有效作品证据。

## 显示规则

- 比较状态时忽略首尾空白和英文大小写。
- `Ongoing`（包括 `OnGoing` 等大小写变体）显示为“连载”。
- `Completed` 的大小写变体显示为“完结”。
- 其他非空状态不猜测含义，保留上游去除首尾空白后的原文。
- 状态为空或只包含空白时不显示。

详情页最终只会在已知状态下显示“连载”或“完结”；`Ongoing`、`OnGoing` 与 `Completed` 本身不会出现在前端。未来上游增加未知状态时，页面会显示其原始文字，而不会错误归入连载或完结。

## 实现边界

- 后端继续解析并透传 Manga18fx 原始状态，不修改领域模型、API 合约、数据库或缓存。
- 前端新增独立纯函数负责状态显示值转换，详情页只消费转换结果。
- 不调整状态所在位置、分隔符、字体、颜色或详情页其他元数据。
- 本次不为状态增加筛选、徽章或主题色。

## 验证

- `Ongoing`、`OnGoing`、全大写和带首尾空白的变体均输出“连载”。
- `Completed`、全小写和带首尾空白的变体均输出“完结”。
- `Hiatus` 等未知值保留原文，首尾空白被去除。
- `null`、空字符串和纯空白输出空值，详情页不渲染状态。
- 前端格式检查、Lint、TypeScript 与生产构建通过。
