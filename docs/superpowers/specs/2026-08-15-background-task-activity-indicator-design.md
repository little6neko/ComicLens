# 后台翻译任务活动指示器设计

## 问题

设置页“后台 OCR 翻译”标题右侧的转圈当前由 TanStack Query 的
`isFetching` 控制。页面每秒轮询一次，单次请求完成后图标会被卸载，下一次请求时
又重新挂载，因此图标反复出现、消失并从头开始旋转，不能准确表达后台任务仍在运行。

## 设计

- 只要后台任务列表非空且任务状态刷新没有报错，标题右侧的加载圈就持续显示并旋转。
- 单次轮询开始或结束不再控制图标的挂载状态，因此动画不会每秒重置。
- 刷新失败时不显示加载圈，继续使用现有错误提示条说明正在保留上一次结果。
- 没有后台任务时，整个后台任务区域继续按现有逻辑隐藏。

## 范围

仅调整 `BackgroundTranslationTasks` 中标题图标的渲染条件。不修改轮询频率、后端任务、
OCR/翻译流程、任务进度计算或强制停止逻辑。

## 验证

- 前端格式检查、ESLint、TypeScript 类型检查和生产构建均通过。
- 代码检查确认图标条件由短暂的请求状态改为后台任务是否存在。
- 错误提示和空任务隐藏行为保持不变。
