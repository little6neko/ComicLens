# 预先翻译弹窗底部圆角修复设计

## 问题

桌面端预先翻译弹窗的外层容器使用圆角，但没有裁剪内部内容。底部操作栏拥有独立背景，因此背景会绘制到外层容器的左右下角之外，使两个下角看起来是直角。

## 设计

在预先翻译弹窗的最外层 `Dialog.Content` 上启用内容裁剪，使选择页、加载页、错误页和批次进度页的子元素统一服从弹窗外壳的圆角边界。

- 桌面端继续使用现有 `rounded-3xl` 圆角。
- 移动端继续保持现有全屏直角布局。
- 不给底部操作栏单独添加圆角，避免不同内容状态出现不一致。
- 不改变弹窗尺寸、滚动区域、底栏布局或交互行为。

## 验证

- 运行前端格式、静态检查和生产构建。
- 在桌面宽度确认左右下角与顶部圆角一致，底栏背景不再越界。
- 在移动端宽度确认弹窗仍为全屏布局，内容区仍可滚动。
