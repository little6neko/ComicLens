# 本地主题、阅读模式与下拉文字清晰度修复设计

## 背景

ComicLens 当前把主题和默认阅读模式与 OCR、翻译等实例级配置一并保存在服务器。前端取得服务器设置后，又通过 `next-themes` 把主题写入浏览器 `localStorage`。当同一浏览器存在多个标签页时，服务器查询缓存和 `next-themes` 的跨标签同步可能形成两个主题写入源，导致深浅主题快速来回切换并最终被旧值覆盖。

设置页下拉浮层还长期设置了 `will-change: transform, opacity`。Chrome 因此在打开动画结束后仍将整个浮层保留为独立 GPU 合成层，文字抗锯齿持续变软，表现为弹窗文字始终模糊。

本轮将主题和阅读模式改成纯浏览器偏好，删除对应服务端字段及数据库内容，并移除下拉浮层的常驻合成提示。其他设置的数据归属和交互保持不变。

## 已确认目标

- 主题只保存在当前浏览器，选择“跟随系统 / 浅色 / 深色”后立即生效。
- 阅读模式只保存在当前浏览器，选择“条漫 / 单页 / 双页”后立即生效。
- 两项均不再等待或依赖页面底部的“保存全部设置”。
- 同源的多个浏览器标签页自动同步主题和阅读模式，不再发生主题相互覆盖。
- 主题切换继续保留项目现有的深浅过渡效果，不启用 `disableTransitionOnChange`。
- 服务端响应、请求模型、设置定义和数据库中彻底删除 `theme`、`reading_mode`，不保留旧字段兼容。
- 下拉展开动画结束后文字恢复正常清晰度；展开方向、时长和当前交互不变。

## 数据所有权

### 主题

主题继续由现有 `next-themes` 管理，沿用其默认 `theme` 本地存储键：

- 缺少本地值时默认为 `system`。
- `system` 通过 `prefers-color-scheme` 跟随操作系统。
- 同源标签页通过 `next-themes` 已有的 `storage` 事件同步。
- 前端不再从 `/api/settings` 读取主题，也不再向该接口提交主题。
- `ThemeProvider` 不设置 `disableTransitionOnChange`，因此不会主动禁用现有 CSS 过渡。

### 阅读模式

新增一个边界明确的浏览器阅读偏好模块，使用 `comiclens-reading-mode` 本地存储键：

- 合法值为 `strip`、`page`、`double`，缺失或无效时默认为 `strip`。
- 读取、校验、写入和订阅逻辑集中在该模块，设置页和阅读器不直接操作存储键。
- 写入后立即更新当前页面，并通过浏览器 `storage` 事件更新同源的其他标签页。
- 模块同时发送当前文档内的自定义变更通知，确保同一标签页内的所有订阅者使用同一个值。
- 若浏览器拒绝访问 `localStorage`，当前标签页仍以内存值即时工作，但刷新持久化和跨标签同步不可用。

主题和阅读模式是设备浏览器级偏好，不跨浏览器或设备同步。这与参考项目 jm-boom 的主题数据归属一致。

### 继续由服务器保存的设置

以下字段仍由 `/api/settings` 和页面底部保存按钮管理：

- 翻页方向；
- 进入章节时默认实时翻译；
- OCR、翻译服务、并发、超时和长图参数；
- 缓存上限及所有敏感接口信息。

阅读器内修改翻页方向的现有即时服务器保存行为保持不变。本轮不把翻页方向迁移到浏览器本地。

## 设置页交互

主题控件直接使用 `useTheme()` 的当前值和 `setTheme()`：

1. 用户选择新主题；
2. `next-themes` 立即更新根元素 class 和本地存储；
3. 其他标签页收到存储事件后同步；
4. 不产生 `/api/settings` 请求，也不改变服务器设置草稿。

默认阅读模式控件直接使用浏览器阅读偏好模块：

1. 用户选择新模式；
2. 当前设置页立即显示新值并写入本地存储；
3. 已打开的阅读器标签页立即切换布局；
4. 条漫模式下继续隐藏设置页的翻页方向字段，单页或双页模式下显示；
5. 不产生 `/api/settings` 请求，也不改变服务器设置草稿。

两项仍显示在“阅读”分区，但与服务器表单草稿解耦。点击“保存全部设置”只提交其余服务器字段，保存成功也不会重写主题或阅读模式。

## 阅读器交互

阅读器直接订阅浏览器阅读模式，不再从服务器设置读取 `readingMode`，也不再维护一次性的 `modeOverride`：

- 打开章节时立即使用本地阅读模式；没有本地值时使用条漫。
- 阅读设置小窗中选择模式后立即写入浏览器偏好并切换布局。
- 设置页与阅读器、同一浏览器的不同标签页保持同步。
- 切换到条漫时继续滚动到当前页；单页和双页的页码归整逻辑保持现状。
- 阅读器仍查询服务器设置，以取得实时翻译默认值和翻页方向。
- 章节切换不再重置阅读模式；浏览器偏好持续生效。

## 服务端与数据库删除

服务端进行完整删除，而不是隐藏或忽略旧字段：

- 从 `ServerSettings` 和 `ServerSettingsPatch` 删除 `theme`、`reading_mode`。
- 从 `SETTING_DEFINITIONS` 删除两项，服务器不再初始化、读取、校验或返回它们。
- `/api/settings` 的 JSON 响应不再包含 `theme`、`readingMode`。
- `/api/settings` 的 PATCH 请求若仍携带这两个旧字段，将作为未知字段返回校验错误，不静默兼容。
- 新增数据库迁移，执行 `DELETE FROM app_settings WHERE key IN ('theme', 'reading_mode')`，物理删除现有记录。
- 新数据库从一开始就不会创建这两条设置记录。

不把旧服务端主题或阅读模式迁移到浏览器。升级后，主题沿用该浏览器现有的 `next-themes` 本地值；阅读模式没有本地值时直接采用条漫默认值。

## 下拉文字清晰度

共享设置下拉保留现有 150ms 的纵向淡入淡出动画和 Popper 定位，仅删除 `.settings-select-content` 上常驻的 `will-change: transform, opacity`：

- 动画执行期间浏览器仍可临时建立合成层，动画中的极短小数位移可能有瞬时软化。
- 动画结束后 `transform` 回到 `none`、`opacity` 回到 `1`，浏览器可撤销浮层自身的合成层，文字恢复正常栅格化。
- 不改变浮层圆角、阴影、滚动跟随、触控滚动、外部关闭或键盘操作。
- 阅读器设置菜单的 `will-change` 不在本轮范围内，因为用户报告的是设置页下拉，且两者是不同组件。

实施验证必须通过 Chrome 合成层信息确认：动画结束后 `.settings-select-content` 不再因 `WillChangeTransform` 或 `WillChangeOpacity` 单独合成。

## 错误与边界处理

- 本地阅读模式值无效时忽略该值并回退条漫，不让错误字符串进入 UI。
- 本地存储写入失败不阻塞当前标签页切换，也不显示与服务器保存有关的错误提示。
- 服务器设置读取或保存失败不会影响本地主题和阅读模式。
- 系统主题变化只在当前主题为 `system` 时改变实际深浅显示，显式浅色或深色不受影响。
- 主题和阅读模式的本地修改不会触发“设置已保存到服务器”提示；服务器字段保存成功提示保持现状。

## 验证方案

### 前端行为

- 深色状态选择浅色后只发生一次有效主题变化，并稳定停留在浅色。
- 选择跟随系统后，模拟系统深浅变化，页面只按系统状态切换。
- 两个同源标签页中修改主题，另一标签同步且不反复闪烁。
- 主题切换期间不存在由 `disableTransitionOnChange` 注入的全局禁用过渡样式。
- 设置页修改阅读模式后立即改变选中值；打开阅读器时使用同一模式。
- 两个标签页中修改阅读模式，另一标签立即切换。
- 重新载入页面后两项仍使用浏览器本地值。
- 点击“保存全部设置”时请求体不包含 `theme` 或 `readingMode`。
- 设置页和阅读器切换阅读模式时均不产生 PATCH 设置请求。

### 服务端与迁移

- 全新数据库和升级数据库的 `app_settings` 都不包含 `theme`、`reading_mode`。
- `/api/settings` GET 响应不含两项。
- PATCH 携带任一旧字段返回 422；其余字段仍可正常保存和持久化。
- 数据库迁移版本测试更新并覆盖旧记录删除。
- 敏感字段加密、设置逻辑迁移和跨字段校验测试继续通过。

### 视觉与工程检查

- 在深色和浅色主题下检查全部设置下拉，动画结束后文字清晰。
- 使用 Chrome 记录动画中和动画后的位置、transform、opacity 与合成原因。
- 桌面滚轮、手机触控拖动、外部轻点、选择、Escape 和焦点返回行为保持正常。
- 运行后端测试、前端格式检查、Lint、TypeScript 与生产构建。
- 重启监听 `0.0.0.0:8233` 的服务后检查健康接口、设置页和阅读器入口。

## 非目标

- 不将其他服务器设置迁移到浏览器。
- 不为主题或阅读模式增加账号级、跨设备同步。
- 不改变翻页方向的存储位置或阅读器即时保存行为。
- 不重做主题颜色、渐变时长、设置页布局或阅读器布局。
- 不改变阅读器设置菜单动画。
