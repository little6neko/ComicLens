# ComicLens 圆形按钮与探索页修复设计

## 目标

修复探索页的分类和搜索按钮显示问题，并让 ComicLens 的按钮形态与 `jm-boom` 保持一致：纯图标按钮使用正圆形，带文字按钮使用胶囊形。同时取消设置页保存按钮的悬浮效果。

## 范围

本次只调整前端视觉样式和布局，不修改 Manga18fx 抓取、特殊路径路由、API、数据库或服务器设置格式。

按钮规则应用于共享按钮组件及所有使用该组件变体的链接按钮，包括搜索、返回、分页、分类、保存、重试、收藏和清理缓存等。卡片、输入框、下拉框、开关和普通容器不属于按钮，维持现有圆角。

## 设计

### 共享按钮规范

修改 `buttonVariants`，让 `default`、`sm` 和 `lg` 尺寸的文字按钮统一使用完全圆角的胶囊形；`icon` 尺寸统一使用完全圆角的正圆形。现有颜色、边框、尺寸、禁用状态、焦点环和交互状态保持不变。

页面中绕过共享变体、手写样式的分页数字按钮同步改为正圆形。阅读器中已有明确 `rounded-full` 覆盖的暗色按钮不改变其颜色和布局；分段式阅读模式控件不是独立的胶囊按钮组，不在本次重构范围内。

### 探索页

`Manhwa Raw` 继续使用后端的特殊分类 ID 和 `/manhwa-raw` 抓取路径，但前端不再根据 `source_special` 使用主色填充。它与所有普通分类一样显示为 outline 胶囊按钮，避免持续呈现黑色，也不暗示它来自另一个数据源。

搜索表单的 flex 容器增加明确的垂直居中规则。搜索提交按钮使用共享的圆形 `icon` 变体，使图标按钮在搜索框内水平、垂直居中。搜索结果页采用同样规则，防止两个搜索入口出现不同表现。

### 设置页

“保存全部设置”仍是设置表单的最后一个操作，保持右对齐、原有尺寸、加载状态和阴影。移除其 `sticky`、底部偏移和悬浮层级，使按钮随正常文档流排列；用户滚动到表单末尾时才会看到它。

## 状态与错误处理

本次不改变业务状态或错误处理。按钮禁用、加载文案、表单提交、重试行为以及 `Manhwa Raw` 的导航参数均保持现状。视觉变化不能影响键盘焦点环、可访问名称或点击区域。

## 验证

- 检查探索页浅色和深色模式，确认 `Manhwa Raw` 与普通分类视觉一致。
- 检查探索页和搜索结果页，确认搜索图标按钮在输入区域居中且为正圆形。
- 检查首页、探索子页、详情、历史、收藏、设置和阅读器的常用按钮，确认文字按钮为胶囊形、纯图标按钮为正圆形。
- 检查分页数字和前后翻页按钮均为正圆形。
- 在移动端和桌面端检查设置页，确认保存按钮只出现在表单末尾且不会悬浮。
- 运行前端测试、TypeScript 检查和生产构建。

## 不在范围内

- 不改变主题色、卡片圆角、输入控件圆角或页面信息架构。
- 不改变 `Manhwa Raw` 的名称、内容、排序或抓取路径。
- 不新增自动保存、未保存提示或保存栏。
