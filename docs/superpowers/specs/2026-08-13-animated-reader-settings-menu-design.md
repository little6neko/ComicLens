# ComicLens 动画阅读设置菜单设计

## 目标

将阅读器底部的“阅读设置”从带遮罩的固定 Dialog 改成参考 jm-boom 的锚定式小窗。菜单应从“阅读设置”按钮上方平滑弹出，不中断漫画浏览；同时明确条漫模式没有左右翻页方向。

## 交互与视觉

- 阅读设置使用 Radix DropdownMenu，由底部胶囊内现有“阅读设置”按钮触发。
- 小窗定位在触发按钮上方，靠近底部胶囊右侧，并自动避开视口边缘。
- 打开动画为约 100–150ms 的淡入、轻微上移和 `95% → 100%` 缩放；关闭时反向播放。
- 不显示全屏遮罩，不锁定页面滚动；点击菜单外或按 Escape 关闭。
- 菜单使用圆角、半透明深色背景、细边框、阴影和背景模糊，与现有阅读器胶囊一致。
- 菜单打开期间，阅读器上下控制栏保持显示，避免触发按钮在菜单下方消失。

## 阅读选项

- 保留三种服务器设置值及布局逻辑：`strip`、`page`、`double`。
- 用户界面名称依次为“条漫”“单页”“双页”；不再出现“纵向”。
- 当前模式显示选中标记。
- “翻页方向”只在“单页”或“双页”模式下渲染。
- 条漫模式不显示翻页方向，因为其通过纵向滚动阅读，不存在左右翻页。
- 切换模式或方向后立即沿用现有 API 保存到 ComicLens 服务器，菜单保持打开，以便连续调整。
- 保存失败沿用现有 Toast 错误提示；本地即时状态保持现有行为，不扩大本次改动范围。

## 组件边界与数据流

- `ReaderBottomBar` 持有 DropdownMenu 的触发器与弹出内容，使 Radix 能以按钮为锚点计算位置。
- 阅读器路由继续持有菜单开关、当前模式、当前方向及保存 mutation，并通过属性传给底部栏。
- 原 `ReaderSettingsPanel` 删除；`ReaderChapterDirectory` 仍使用现有侧边 Dialog，不受本次改动影响。
- 菜单开关仍参与 `heldOpen`，复用现有 `useReaderChrome` 行为。
- 数据流保持为：点击选项 → 路由更新本地 override → PATCH 服务器设置 → 更新查询缓存。

## 可访问性与响应式

- 使用 Radix DropdownMenu 的焦点管理、键盘导航、Escape 关闭和外部点击关闭能力。
- 触发按钮保留可见文字和按钮语义。
- 小屏幕限制菜单宽度，不越出视口；桌面端从触发按钮上方靠右展开。
- 尊重浏览器的 reduced-motion 偏好，由现有 Tailwind 动画体系降低或取消动画。

## 验证

- 前端格式检查、Lint、TypeScript 与生产构建通过。
- 浏览器验证小窗相对“阅读设置”按钮从上方打开，存在打开和关闭动画且没有遮罩。
- 验证底部按钮顺序保持“上一话、下一话、目录、阅读设置”。
- 验证条漫模式显示“条漫”且不出现翻页方向。
- 验证单页、双页模式均显示翻页方向，切换后服务器设置同步更新。
- 验证点击外部和 Escape 均可关闭菜单，目录抽屉行为不变。

## 非目标

- 本次不添加 jm-boom 的双页开关、页码胶囊、自动阅读或其他设置。
- 本次不改变漫画布局、翻译调度、章节目录和服务器设置的数据结构。
