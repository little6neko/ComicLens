# 漫画详情页章节正逆序设计

## 背景

ComicLens 漫画详情页的“章节”标题右侧目前只显示章节总数，章节列表沿用 Manga18fx 返回的顺序。需要参考 jm-boom，将该位置改为可点击的正逆序按钮，让用户在最新话优先与最早话优先之间切换。

## 交互与视觉

- 默认保持当前的最新话优先顺序。
- “章节”标题右侧使用现有小号圆角描边按钮，显示“X 话”和当前方向对应的升序或降序图标。
- 点击按钮立即反转章节列表，再次点击恢复原顺序。
- 排序状态只存在于当前详情页组件中；刷新页面或重新进入详情页后恢复默认的最新话优先。
- 按钮提供可访问名称和当前排序方向提示，键盘可正常操作。

## 数据与行为边界

- 不修改 Manga18fx 返回数据、后端 API、服务器设置或数据库。
- 只改变详情页章节列表的展示顺序；章节链接、标题、更新时间和已读灰色样式保持不变。
- “开始阅读”与“从第 X 话继续”的目标继续基于原始稳定章节顺序和阅读历史计算，不受列表临时排序影响。
- 单话漫画仍显示排序按钮和“1 话”；点击不会产生可见顺序变化，行为与 jm-boom 的章节标题控件保持一致。

## 实现方式

在详情页加入默认值为 `true` 的降序状态，根据该状态选择原始章节数组或其副本的反转结果。渲染章节列表时使用派生数组，避免原地修改查询缓存中的漫画详情。按钮复用项目现有 `Button`，图标使用 Lucide 的窄宽升降序图标。

## 验证

- 多话漫画首次进入时保持最新话在前。
- 点击按钮后最早话在前，图标与可访问提示同步变化；再次点击恢复。
- 切换排序后已读章节仍对应正确章节，链接仍进入正确章节。
- 刷新页面恢复最新话在前。
- 继续阅读文案和目标不因切换排序而变化。
- 前端格式检查、Lint 和生产构建通过。
