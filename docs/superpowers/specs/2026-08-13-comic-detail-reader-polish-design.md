# ComicLens 详情页与阅读器细节调整设计

## 目标

在不改变现有阅读、历史和章节导航逻辑的前提下，补充 Manga18fx 的作品发行日期，统一详情页与阅读器目录的已读视觉状态，取消阅读器控制栏的定时隐藏，并优化章节目录与继续阅读文案。

本次包含五项产品行为：

1. 详情页显示 Manga18fx 的 `Release` 元数据。
2. 详情页和阅读器章节目录中的已读章节仅以灰色表示，不使用勾号。
3. 阅读器控制栏不再在 3 秒后自动消失。
4. 阅读器底部“目录”按钮改为“章节目录”。
5. 多话作品的继续阅读按钮显示“从第 X 话继续”。

## Release 数据

### 领域模型与来源解析

`ComicDetail` 新增可空字符串字段 `release_label`，前端 API 类型对应 `releaseLabel: string | null`。该字段是来源展示值，不转换为日期对象，也不补造月、日或时区。

`Manga18fxSource.detail()` 从现有详情元数据映射中读取 `Release`，去除首尾空白后写入 `release_label`。例如来源值为 `2025`，API 返回 `"releaseLabel": "2025"`。来源没有该项或内容为空时返回 `null`。

该字段使用明确类型而不是返回任意元数据字典，避免将 Manga18fx 页面结构泄露给前端，也不需要数据库迁移。封面本地化过程只替换封面 URL，继续原样保留该字段。

### 详情页展示

详情页在作者、绘者等作品信息区域显示：

`发行日期 2025`

标签使用次要文字色，值使用正常前景色，与作者和绘者的定义列表布局一致。`releaseLabel` 为空时整项不渲染，不显示破折号或“未知”。

## 继续阅读文案

### 行为

- 没有有效历史记录：保持“开始阅读”。
- 只有一话且存在有效历史记录：保持“继续阅读”。
- 多话且存在有效历史记录：显示“从第 X 话继续”。

历史章节必须仍存在于当前作品章节列表中才算有效；无效历史按“开始阅读”安全回退。

### 话数解析与回退

新增纯前端章节展示辅助函数，先从历史章节标题中提取来源的实际话数。识别不区分大小写的明确章节标记，例如：

- `Chapter 113` → `113`
- `Chapter 12.5` → `12.5`
- `Ch. 7` → `7`

提取只接受紧随 `Chapter` 或 `Ch.` 标记的数字及可选小数，不能从日期、作品名或其他无标记数字中猜测话数。保留来源数字文本，不把 `12.5` 四舍五入。

标题无法可靠提取时，将 Manga18fx 返回的新到旧章节列表反转为最旧到最新的阅读顺序，并使用历史章节在该序列中的一基位置作为稳定回退值。例如最旧章节显示第 1 话。最终按钮文案为 `从第${number}话继续`。

继续阅读目标的章节 ID 和页码仍沿用现有历史数据，仅改变按钮标签。

## 已读章节样式

### 数据来源

详情页继续使用现有 `/api/comics/{comicId}/read-chapters` 精确集合。

阅读器新增同一查询，并将 `chapterIds` 传给 `ReaderChapterDirectory`。当前章节被标记已读后，现有 `setChapterRead` mutation 返回的完整集合继续写入同一 React Query 缓存，因此目录无需额外接口或轮询即可更新。读取失败只暂时不显示已读灰色，不阻断详情或阅读器。

### 详情页

移除章节行尾的已读勾号。已读章节整行使用主题语义色：

- `muted` 背景；
- `muted-foreground` 标题和更新时间；
- 与普通章节相比更弱的边界/分隔视觉；
- 悬停和键盘焦点时仍提供清晰反馈，并保持链接可点击。

样式只使用现有主题变量，不使用只适合单一主题的固定灰色，因此在浅色和深色模式下均保持可读。

### 阅读器章节目录

阅读器目录移除当前章节的勾号。状态优先级为：

1. 当前章节：保留现有高亮边框、背景和前景色，即使它也已读。
2. 已读且非当前章节：使用弱化灰色背景、文字和边框。
3. 未读章节：保持现有样式。

阅读器本体继续使用现有固定深色画布；已读色从现有 zinc 调色板选择具有足够对比度的组合，因此无论全局主题为浅色或深色，目录都保持清晰。当前章节依靠高亮而不是图标识别。

## 阅读器控制栏显隐

`useReaderChrome` 移除 `AUTO_HIDE_MS`、定时器和所有 `scheduleHide` 调用。控制栏首次进入章节时仍显示，之后不会仅因无操作而自动消失。

其余现有行为保持不变：

- 点击漫画区域手动切换显示与隐藏；
- 条漫滚动时隐藏；
- 触摸移动时隐藏；
- 键盘操作时显示；
- 目录或阅读设置打开时强制显示；
- 切换章节时重新显示；
- 控制按钮继续阻止点击事件冒泡。

鼠标移动调用的 `keepVisible` 保留兼容接口，但只确保控制栏可见，不再启动计时。关闭面板后维持当前可见状态，直到用户点击画布或发生现有滚动/触摸隐藏行为。

## 章节目录按钮

底部按钮顺序和布局不变，仅将第三个按钮的可见文字及无障碍标签从“目录”改为“章节目录”：

1. 上一话
2. 下一话
3. 章节目录
4. 阅读设置

现有圆形图标、点击区域和抽屉动画均不修改。

## 测试与验收

### 后端

- Manga18fx 详情 fixture 增加 `Release`，解析测试断言 `release_label`。
- API 测试断言 `releaseLabel` 使用 camelCase 返回并在本地化封面时保留。
- Release 缺失时验证字段为 `null`，详情解析仍成功。

### 前端

前端当前没有组件测试运行器，因此将纯话数解析和继续阅读标签逻辑放在独立辅助模块中，并通过 TypeScript、lint 和生产构建验证调用边界。人工/代码审阅覆盖：

- 多话 `Chapter 113` 显示“从第113话继续”；
- 小数话数和无标记标题的顺序回退；
- 单话保持“继续阅读”；
- 详情页和目录不再渲染已读/当前勾号；
- 当前章节高亮优先于已读灰色；
- 阅读器不存在 3 秒定时隐藏逻辑；
- 按钮文字为“章节目录”。
