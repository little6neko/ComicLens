# 设置页版本区块与后台翻译任务列表设计

## 目标

在 ComicLens 设置页顶部增加类似 jm-boom 的版本信息区块，当前显示 `v0.0.1`；同时优化多个后台 OCR 翻译任务并存时的布局，使 1–4 个任务都能紧凑、清晰地浏览和操作。

本次只调整设置页前端展示，不修改后台任务接口、翻译调度、任务排序或持久化方式。

## 页面顺序

设置页继续使用普通文档流，不增加固定定位、绝对定位或浮层。页面从上到下依次为：

1. 设置页标题和说明；
2. 公开监听且未设置密码时的安全警告；
3. 存在后台翻译任务或任务状态读取失败时的后台 OCR 翻译区域；
4. 版本区块；
5. 阅读、OCR 与翻译、缓存等现有设置；
6. 保存全部设置按钮。

后台任务区域没有任务且读取正常时返回空内容，因此版本区块会自然成为安全警告之后的第一个设置区块。后台任务存在时始终优先显示在版本区块上方，不会被版本信息遮挡。

## 版本区块

### 外观

版本区块复用设置页现有的圆角卡片、边框、阴影和标题结构：

- 标题为“版本”，使用 `PackageIcon`；
- 内容仅有一行；
- 左侧显示“ComicLens”和说明“当前应用版本”；
- 右侧显示带确认图标的描边胶囊徽章 `v0.0.1`；
- 内容行横跨设置卡片的两列，窄屏下仍保持名称与徽章清晰可读。

### 数据来源

新增一个前端版本常量，初始值为 `0.0.1`。版本区块统一在渲染时添加 `v` 前缀。

本次不新增版本 API，不读取数据库，也不把版本号加入服务器设置。前端版本常量保持独立，方便后续替换为构建时注入或软件包元数据，而无需改动版本区块结构。

## 后台 OCR 翻译任务列表

### 总体结构

保留现有“后台 OCR 翻译”标题、任务数量、自动刷新指示和读取失败提示。任务内容从多张独立大卡片改为一个圆角容器中的紧凑列表：

- 无论只有 1 个任务还是存在多个任务，都使用同一套列表布局；
- 每个任务占一行，相邻任务使用分隔线区分；
- 不新增折叠、分页或“主任务”概念；
- 列表顺序完全沿用 API 返回顺序；
- 任务数量变化时不切换布局，避免页面突然重排。

### 单个任务行

每个任务行保留现有状态和操作能力：

- 漫画标题：点击进入漫画详情页；
- 章节名：点击进入对应阅读器；
- 当前阶段：继续使用胶囊状态显示“缓存与切分”“等待开始”“OCR”“翻译”“渲染”“正在停止”或“处理中”；
- 强制停止：保留独立的破坏性圆形按钮及原确认提示；
- 已发现分片时：显示进度条、已完成分片数、总分片数和百分比；
- 尚未发现分片时：显示脉冲进度条和已缓存源图数量；
- 始终保留已缓存源图数量；
- 存在失败分片时：使用醒目的破坏性色文字显示失败数量。

删除原来的“查看章节”按钮，以减少重复操作。章节名本身承担进入阅读器的入口，不减少功能。

### 响应式布局

桌面端将标题信息、阶段状态和强制停止操作排列在任务行顶部，进度条与数值置于下一行并横向对齐。多个任务的进度条起点、阶段和操作位置尽量保持一致，便于快速比较。

手机端允许任务行自然换行：标题区域优先占据可用宽度，阶段和强制停止按钮保持可见，进度信息使用下一行完整宽度。不会为了节省空间隐藏失败数量、源图缓存数量或停止操作。

## 状态与错误处理

以下现有逻辑保持不变：

- 每秒刷新后台任务；
- 后台标签页仍继续刷新；
- 获取失败时保留上一次任务数据并显示警告；
- 强制停止前显示确认提示；
- 停止请求期间禁用对应按钮并显示加载状态；
- 停止成功后更新任务列表、刷新阅读器翻译状态并显示成功提示；
- 停止失败时显示错误提示。

本次仅重组标记结构和样式，不改变查询键、请求函数、缓存更新或 mutation 行为。

## 可访问性

- 后台任务区域继续使用标题关联的 `aria-labelledby`；
- 漫画和章节入口继续使用真实链接；
- 强制停止继续使用真实按钮，并通过按钮文字表达行为和进行中状态；
- 版本徽章仅展示信息，不伪装成可点击控件；
- 浅色和深色主题均使用现有语义颜色，确保文字、分隔线、状态和失败信息可读。

## 验证

实施后执行：

1. `npm run fmt:check`；
2. `npm run lint`；
3. `npm run build`；
4. 检查无任务时版本区块位于设置内容顶部；
5. 检查存在任务时后台进度位于版本区块上方且互不覆盖；
6. 分别检查 1 个和 4 个任务时的统一紧凑列表；
7. 检查桌面和手机宽度下的标题、阶段、进度、失败信息与停止按钮；
8. 检查漫画详情、阅读器跳转和强制停止确认仍可用；
9. 检查浅色和深色主题下的可读性。

## 不在本次范围内

- 服务端版本接口或构建信息接口；
- 数据库版本字段；
- 后台任务折叠、分页、排序或数量限制；
- OCR、翻译、缓存和调度逻辑调整；
- 设置页其他区块的视觉重构。
