# ComicLens 后台 OCR 翻译进度与强制停止设计

## 目标

在设置页顶部集中显示全部正在后台执行的 OCR 翻译任务，并允许用户按话立即强制停止本机处理。强停必须保留可复用检查点、已完成分片和译图，之后可从阅读器继续翻译，同时不得影响其他话的任务。

设置页原“长图高级设置”标题同步改为“OCR 长图高级设置”。

## 设置页布局

- 采用视觉方案 A：在设置页标题与安全警告之后、设置表单之前显示独立的“后台 OCR 翻译”区域。
- 仅当存在活动任务时显示该区域；没有活动任务时不显示空卡片。
- 每个 `comic_id + chapter_id` 显示一张任务卡，多话并行时显示全部卡片。
- 卡片沿用设置页圆角卡片风格，包含：
  - Comic 标题和话标题；
  - 当前阶段标签；
  - 一级分片进度条；
  - `已完成 / 总分片` 和百分比；
  - 失败分片数（大于零时显示）；
  - “强制停止”危险操作按钮。
- 任务仍在缓存和切分、尚未得出准确分片总数时，显示不定进度状态及源图片进度，不伪造百分比。
- 设置页每秒刷新活动任务列表；请求短暂失败时保留上一次成功数据并显示非阻塞错误提示。

## 标题解析

- 后端任务列表返回可直接渲染的 `comic_title` 与 `chapter_title`。
- 优先从 `reading_history` 快照读取 Comic 标题；仅当历史当前话匹配时使用其中的话标题。
- 无历史快照时使用 `comic_id`、`chapter_id` 作为稳定兜底。
- 设置页查询任务时不主动请求 Manga18fx，避免来源不可用拖慢任务管理与强停操作。

## 活动任务与阶段

活动状态包括：`preparing`、`queued`、`running`、`stopping_after_page`、`stopping_after_segment`。

卡片阶段映射：

- `preparing`：缓存与切分；
- `queued`：等待开始；
- 当前分片状态 `ocr`：OCR；
- 当前分片状态 `translating`：翻译；
- 当前分片状态 `rendering`：渲染；
- 停止状态：正在停止；
- 无法进一步细分的 `running`：处理中。

进度继续使用现有一级分片计数：只有分片完成 OCR、翻译、渲染并原子发布后，`completed_segments` 才加一。失败分片不计入完成数，并单独显示失败数。

## 后台任务 API

- 新增只返回所有活动任务摘要的 API，按创建时间排序；不返回完整页面和分片数组，避免设置页每秒轮询大响应。
- 每条摘要包含：任务与话标识、标题、任务种类、状态、阶段、源图片进度、分片进度、失败数和当前分片坐标。
- 新增按 `comic_id + chapter_id` 强停的 API。一次调用强停该话所有活动 generation（包括正常翻译与重新翻译），但不触碰其他话。
- 强停响应返回该话强停后的任务摘要或操作结果，前端随后刷新活动任务列表。

## 强制停止语义

采用按话取消本机协程的方案：

1. 在该话的管理锁范围内标记强停意图并取消对应 `asyncio.Task`。
2. 等待协程收到 `CancelledError` 并退出，确保不再继续轮询 OCR、调用翻译或发布新分片。
3. 在数据库事务中将该话所有活动 generation 标记为 `paused`，清空停止标记和当前页/分片指针。
4. 将其中处于 `downloading`、`ocr`、`translating`、`rendering` 的页，以及处于 `ocr`、`translating`、`rendering` 的分片，恢复为 `pending`。
5. 清除该话缓存 bundle 的 `active_task` 标记，并执行常规缓存上限检查。

强停保留：

- 已缓存原图和 OCR 输入图；
- PaddleOCR `ocr_job_id`；
- 已成功写入的 OCR、文本块和翻译结果检查点；
- 已完成并发布的分片、整页译图与活动图层；
- generation 的语义设置与分片计划。

强停不尝试取消 PaddleOCR 云端任务。云端可能继续运行，但 ComicLens 会立即停止轮询；用户从阅读器重新开启翻译时，优先使用持久化 `jobId` 继续查询。

## 并发与竞态

- 强停只取消与目标 `comic_id + chapter_id` 对应的 worker，不影响其他话。
- manager 在取消并等待旧 worker 完成前，不为同一话启动新 worker。
- 强停完成后，该话状态为 `paused`，启动 API 可按现有语义恢复并创建新 worker。
- 如果任务在强停到达前恰好完成，接口按幂等操作处理：不破坏已完成状态，也不删除结果。
- 连续调用强停保持幂等；没有活动任务时返回成功的空结果，而不是错误。
- 服务关闭继续使用原有全局取消与恢复逻辑；后台强停使用独立的、明确标记为暂停的恢复路径。

## 前端交互

- 点击“强制停止”弹出浏览器确认，文字说明会立即中断本机处理、保留检查点，且云端 OCR 任务可能继续。
- 确认期间仅禁用对应任务卡按钮，其他话仍可操作。
- 成功后从活动列表移除该卡片并显示“已强制停止，可从阅读器继续”的 Toast。
- 失败时保留卡片并显示错误 Toast。
- 活动任务卡中的 Comic/话标题可以链接回对应阅读器，方便查看进度或继续操作。

## 测试与验收

- Repository 测试验证强停恢复处理中页/分片为 `pending`，保留 `ocr_job_id` 和各阶段路径，保留已完成分片。
- Manager 测试使用阻塞 OCR 模拟任务，验证强停会立即取消、状态转为 `paused`、不会继续翻译或渲染，之后恢复可继续。
- 并发测试验证强停一话不影响另一话 worker。
- API 测试验证活动任务只返回活动状态、标题兜底、精简摘要以及幂等强停。
- 前端格式、Lint、TypeScript 和生产构建通过。
- 浏览器验证设置页多卡片布局、阶段与进度显示、二次确认、逐卡禁用和强停后移除。
- 验证设置区标题显示为“OCR 长图高级设置”。

## 非目标

- 不提供 PaddleOCR 云端取消 API；当前服务没有可依赖的云端取消能力。
- 不在设置页显示已暂停、已完成或历史任务。
- 不提供“全部强停”按钮。
- 不改变已有的阅读器普通关闭语义；阅读器关闭翻译仍是完成当前分片后暂停。
- 不删除任务缓存、OCR 结果或译图。
