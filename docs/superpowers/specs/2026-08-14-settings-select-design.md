# 设置页圆角下拉组件设计

## 背景与目标

ComicLens 设置页目前使用浏览器原生 `<select>`。关闭状态虽然已有圆角，但系统箭头紧贴右边缘，且浏览器或操作系统绘制的展开列表通常是方形，无法与项目现有的大圆角卡片、圆形按钮和柔和浮层保持一致。

本功能将设置页全部下拉框改为统一、可控的圆角浮层组件，同时保持现有字段值、保存流程和条件显示逻辑不变。

## 已选方案

采用项目现有依赖中的 Radix Select，并封装为 ComicLens 通用 UI 组件。相比保留原生 `<select>`，该方案能同时控制关闭状态和展开浮层；相比自行实现弹出菜单，它可直接获得键盘导航、焦点管理和触摸操作等无障碍能力。

视觉采用已确认的 B 方案：触发器与浮层均为统一的大圆角矩形，不使用完整胶囊，也不将打开后的触发器与菜单拼成连体面板。

## 组件边界

新增 `web/src/components/ui/select.tsx`，由组件统一负责：

- Radix Select 的 Root、Trigger、Value、Icon、Portal、Content、Viewport、Item 和 ItemIndicator 组合。
- 触发器、箭头、浮层、选项及勾选图标的样式。
- 打开与关闭动画、碰撞检测、浮层层级和与触发器等宽。
- 鼠标、触摸和键盘交互，以及关闭后的焦点返回。

设置页只负责传入当前值、可选项目、变更回调、可选宽度样式和无障碍名称，不重复定义下拉内部结构。

## 视觉规格

### 触发器

- 高度保持 `44px`，普通设置下拉占满字段宽度。
- 使用约 `16px` 的大圆角矩形，与设置页输入框和卡片的圆角语言协调，但不使用完整胶囊。
- 保留当前主题的背景、细边框和文字尺寸。
- 左侧文字距边缘 `16px`；右侧箭头距边缘也为 `16px`，两侧留白对称。
- 箭头使用现有 Lucide 图标，颜色为弱化文字色；打开时旋转 `180°`。
- hover、focus-visible 和 disabled 状态使用现有主题变量，焦点样式与其他表单控件一致。

### 浮层与选项

- 浮层与触发器等宽，使用约 `16px` 圆角、细边框、主题背景和柔和阴影。
- 浮层与触发器之间保留小间距，并由 Radix 自动避让视口边界。
- 每项保留足够触摸高度，项目本身使用较小的圆角矩形。
- 当前项显示浅色圆角背景、较明确文字色和右侧勾选图标。
- 鼠标悬停与键盘聚焦显示同类浅色圆角背景。
- 深色和浅色主题均复用现有语义色，不新增固定主题配色。

### 动画

- 打开时以约 `150ms` 淡入，并伴随轻微缩放和沿弹出方向的小幅位移复位。
- 关闭时以相同视觉语言平滑淡出、缩小和移开。
- 箭头旋转与浮层开关同步。
- 在 `prefers-reduced-motion: reduce` 下取消缩放、位移和旋转，仅保留即时状态变化或极短淡化，避免强制动态效果。

## 替换范围

设置页现有两类原生下拉全部替换：

1. 普通设置：主题、默认阅读模式、翻页方向、源语言、翻译服务。
2. 敏感字段操作：OCR 异步任务 URL、OCR Token、DeepL API Key、DeepLX URL、回退代理 URL 对应的“保留 / 替换 / 清除”选择器；条件显示行为保持原样。

敏感字段操作下拉保持窄版布局，但宽度需要容纳文字、左右对称留白和箭头，不允许文字或图标相互挤压。普通设置下拉继续占满当前字段宽度。

本轮不修改阅读器内的阅读设置菜单，也不更改 Input、Switch、设置分区、字段排列或保存按钮。

## 行为与数据边界

- 所有选项值和显示文字保持不变。
- `onValueChange` 继续更新现有 draft；提交仍由“保存全部设置”一次性写入服务器。
- 条漫模式下隐藏翻页方向、DeepL 与 DeepLX 密钥字段切换等条件渲染逻辑保持不变。
- 敏感字段从“保留”切换到其他动作时，仍沿用当前清空输入值的行为。
- 不引入新的后端字段、API、数据库迁移或设置默认值。

## 无障碍与响应式

- 支持 Tab 聚焦、方向键移动、Enter/Space 打开和选择、Escape 关闭。
- 当前项、禁用状态和展开状态由 Radix 的语义与 ARIA 属性表达。
- 浮层关闭后焦点返回对应触发器。
- 普通字段使用可见标签提供名称；敏感字段窄版操作下拉继续获得包含字段名称的无障碍标签。
- 桌面端与移动端统一使用同一圆角浮层，不回退到系统原生选择器。
- 浮层在窄屏内进行碰撞避让，不越出可视区域。

## 验证

- 设置页不再存在原生 `<select>`。
- 五个普通设置下拉和全部敏感字段操作下拉都使用统一组件。
- 触发器左右留白对称，箭头不贴右边；普通与窄版触发器均无拥挤或截断。
- 浮层、选项、当前项、勾选、hover/focus 和开关动画符合已确认的 B 方案。
- 条件字段切换与“保存全部设置”行为保持正确。
- 使用鼠标、触摸和键盘分别验证打开、选择、关闭与焦点返回。
- 检查浅色、深色主题及移动端宽度。
- 前端格式检查、Lint、TypeScript 和生产构建通过。

## 非目标

- 不修改任何设置含义、默认值或服务器存储逻辑。
- 不把其他页面的菜单或阅读器弹窗迁移到该组件。
- 不重做所有文本输入框或设置页整体布局。
