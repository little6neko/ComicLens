# ComicLens 译图状态画布设计

## 目标

翻译模式下不再以原图作为阅读器底图。阅读器改为按页面和分片状态绘制译图画布：只有成功发布的译图可见；尚未完成的区域保持空白并显示“翻译中”；失败区域在准确位置显示错误信息和单片重试按钮。

该设计解决任务顶部只能看到类似 `97 / 98 · 1 失败`，却无法在正文中辨认失败位置的问题。关闭翻译模式后仍立即恢复完整原图。

本文取代 `2026-08-13-progressive-segment-reader-design.md` 中“完整原图永远是最底层”“待处理或失败区域显示原图或旧译图”的阅读器显示约定；后端缓存、调度、渐进发布和暂停规则不变。

## 已确认行为

- 翻译模式关闭时，阅读器只显示原图，不显示译图状态或覆盖层。
- 翻译模式开启时，DOM 中不渲染原图，也不把原图作为透明或模糊底图。
- 页面尺寸或分片计划尚不可用时，显示高度为 `50dvh` 的深色占位，居中显示“翻译中”。
- 页面尺寸和分片计划可用后，画布按照源页宽高保持准确纵横比；每个分片按照服务端提供的显示边界占据准确区域。
- 成功分片只显示对应译图，不附加“已完成”标签。
- `pending`、`ocr`、`translating`、`rendering` 状态均显示空白区域和“翻译中”。
- `failed` 状态显示空白区域、准确位置、错误摘要和“重新翻译”按钮，不显示原图或旧译图填补该区域。
- 单片重试提交成功后，该区域立即恢复“翻译中”；重试失败则保留原失败状态并显示现有操作错误提示。
- 单页、双页和条漫模式使用相同状态语义。

## 状态画布

`ReaderPageImage` 保留为单个源页的渲染边界，但内部按模式选择两条互斥路径：

1. 原图路径：翻译关闭时渲染现有原图 `<img>`。
2. 译图路径：翻译开启时渲染不含原图的状态画布。

已知源页宽高时，状态画布只使用数值尺寸建立纵横比。条漫模式下画布占满阅读列宽；单页和双页模式下同时受可用宽度与视口高度约束，保持完整页面可见。未知尺寸时使用半屏高占位，取得页面或首批分片尺寸后切换为准确纵横比。

画布底色使用阅读器现有深色背景。已规划的分片按 `displayTop / sourceHeight` 和 `(displayBottom - displayTop) / sourceHeight` 计算纵向位置与高度。相邻分片的占位和译图首尾相接，因此不会露出原图，也不会因为单片失败压缩后续内容。

## 分片显示决策

当前 generation 存在分片记录时，以 `segments` 为唯一状态来源：

- `completed` 且存在 `translatedUrl`：显示该分片译图。
- 其他进行中状态：显示“翻译中”占位。
- `failed`：显示失败占位。
- 状态为 `completed` 但译图 URL 缺失，或译图资源加载失败：按失败占位处理，错误文案为“译图加载失败”，不回退到原图。

这意味着重新翻译本话时，当前 generation 尚未完成或失败的区域也保持空白，不使用旧 generation 的译图填补。用户看到的内容与本次任务的 `completedSegments` 进度严格一致。

没有当前分片记录时，为兼容已经缓存的旧整页译图：仅当服务端明确返回成功的整页译图层时显示该译图；其余情况显示半屏“翻译中”占位。新任务一旦返回分片计划，就切换到分片状态画布。

## 失败定位与重试

失败占位显示：

- 人类可读位置：`第 {pageIndex + 1} 页 · 第 {segmentIndex + 1} 片`；
- 全话位置：存在总数时显示 `全话第 {globalIndex + 1}/{totalSegments} 片`；
- 服务端安全错误摘要，例如 `OCR服务请求失败，状态码 500`；
- 圆形风格的“重新翻译”胶囊按钮。

按钮继续调用现有分片重试接口：

`POST .../translation/pages/{pageIndex}/segments/{segmentIndex}/retry`

按钮点击阻止阅读器点击事件冒泡，避免同时切换上下控制栏。请求进行时按钮禁用并显示旋转图标；接口返回的新任务状态直接写入查询缓存。任务进入活动状态后，现有一秒轮询继续更新该分片，直至成功或再次失败。

本次已定位的失败会显示为：`第 10 页 · 第 4 片 · 全话第 73/98 片`，错误为 `OCR服务请求失败，状态码 500`。

## 数据与接口边界

现有 API 已提供实现所需字段：页面宽高、分片状态、显示边界、全局序号、译图 URL、错误对象和全话总分片数；现有接口也已支持单片重试。因此本次不修改数据库结构和后端翻译调度，仅调整阅读器状态组合与渲染。

前端合并 manifest 与当前任务时继续以当前任务页面状态优先。状态画布组件额外接收 `totalSegments`，只用于显示全话失败位置，不参与坐标计算。

## 错误与竞态处理

- 开启翻译时先在本地切换到状态画布，再发起或恢复翻译任务，因此不会在网络请求期间继续显示原图。
- 关闭翻译时先在本地恢复原图，再发送暂停请求，保持现有即时切换行为。
- 重试接口成功但轮询尚未开始时，以返回任务中的 `pending` 状态显示“翻译中”。
- 译图 `<img>` 加载出错后只替换为译图加载失败状态，不泄露原图底层。
- 快速开关翻译不会共享两条渲染路径的图片节点，避免原图短暂闪现。

## 验证

前端状态决策应覆盖以下情况：

1. 翻译关闭时只渲染原图。
2. 开启翻译但尚无页面尺寸时显示半屏占位。
3. 已规划页面按真实纵横比显示，成功、处理中和失败分片位置连续且准确。
4. 失败文案包含页码、页内片号和全话片号。
5. 点击单片重试不会触发阅读器控制栏显隐，并在请求成功后变为“翻译中”。
6. 译图资源加载失败时不回退到原图。
7. 关闭翻译后立即恢复原图。
8. 条漫、单页、双页三种模式均保持比例且不显示原图底层。
