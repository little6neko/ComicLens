# ComicLens 译图状态画布实施计划

## 目标

按已确认的设计，让翻译模式只显示成功译图和分片状态占位，准确标出失败位置并支持单片重试；关闭翻译后立即恢复原图。

## 阶段 1：页面显示状态

- 将 `ReaderPageImage` 的原图路径和译图路径改为互斥渲染。
- 从页面、分片或旧整页译图层解析源图宽高。
- 未知尺寸时显示 `50dvh` 的“翻译中”占位。
- 已知尺寸时在条漫、单页和双页模式中建立保持比例的空白状态画布。

## 阶段 2：分片状态与失败定位

- 当前 generation 有分片时，只按 `segments` 渲染。
- 成功分片显示 `translatedUrl`；处理中分片显示“翻译中”。
- 失败分片显示页码、页内片号、全话片号、错误摘要和现有单片重试按钮。
- 译图 URL 缺失或图片加载失败时显示“译图加载失败”，不回退原图。
- 无分片的旧缓存仅兼容成功的整页译图层。

## 阶段 3：路由接线

- 向条漫及分页阅读中的 `ReaderPageImage` 传入任务总分片数。
- 保留现有重试 mutation、查询缓存更新和一秒活动任务轮询。
- 确认按钮继续阻止点击冒泡。

## 阶段 4：验证与交付

- 格式化前端代码并运行格式检查、lint、TypeScript 与生产构建。
- 运行完整后端测试，确认 API 无回退。
- 检查生产构建中不再出现原图作为翻译画布底层的代码路径。
- 用当前 `97 / 98 · 1 失败` 任务验证 API 数据能映射为“第 10 页 · 第 4 片 · 全话第 73/98 片”。
- 提交实现、重启 `comiclens.service`，并检查 `0.0.0.0:8233` 与健康接口。
