# ComicLens 流式切片队列实施计划

## 目标

按已确认的设计，把渐进翻译从“整话预切片后串行处理”改为“逐页生产分片、同时按序消费”，
并将 OCR 默认切片更新为 `1600/200`、彻底移除 `useOcrForImageBlock`。完成后清除旧翻译派生
缓存与任务记录，保留原始漫画、封面和用户设置。

## 阶段 1：默认参数与增量分片事实模型

- 将渐进流水线版本升级，更新设置默认值和旧默认值迁移。
- 从 PaddleOCR multipart 中删除 `useOcrForImageBlock`。
- 为仓储新增“按页原子追加分片”和“标记规划完成”操作。
- 保证重复准备同一页不会重复插入或重复增加 `total_segments`。
- 增加设置迁移、OCR payload、动态总数和幂等追加测试。
- 运行相关后端测试并提交。

## 阶段 2：生产者—消费者调度

- 将 `SegmentPlanner` 拆为逐页准备接口，复用已有原图和完整 OCR 输入切片。
- 在渐进 generation 内并行运行顺序准备生产者与顺序分片消费者。
- 使用数据库作为事实来源、`asyncio.Event` 作为唤醒信号。
- 消费者在规划未完成且暂时无分片时等待，规划完成后才允许收尾。
- 处理生产者异常、普通暂停、强制停止、重启恢复及任务互相取消。
- 增加首图先 OCR、动态 `3/5 → 3/10`、严格顺序、暂停和恢复测试。
- 运行翻译管理器测试并提交。

## 阶段 3：动态进度界面与文档

- 阅读器顶部在已有分片时立即显示进度，不以 `planningComplete` 为显示门槛。
- 设置页后台任务卡片同时显示当前分片进度和源图准备数量。
- 更新设置提示、README 和旧设计中的现行行为说明。
- 运行前端 lint、TypeScript 与生产构建并提交。

## 阶段 4：全量验证与派生缓存清理

- 运行完整 pytest、Ruff、前端 lint 和生产构建。
- 检查当前活动任务并停止 ComicLens 服务，记录清理前缓存数量和占用。
- 在数据库事务中删除 generation、活动译图及对应缓存索引记录。
- 只删除解析出的 `data/cache/chapters/*/generations` 目录，保留 `originals` 和 `covers`。
- 核对原图数量、设置和密钥记录仍存在，记录清理后数量与占用。
- 重新启动服务，验证 `0.0.0.0:8233`、健康接口及后台任务为空。
- 提交剩余改动并推送 SSH remote。
