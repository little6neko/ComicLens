# ComicLens 分片渐进翻译与阅读器实施计划

## 目标

按已确认的设计，将章节翻译改为整话预缓存、严格串行的分片流水线，并完成 jm-boom 式阅读器上下控制栏。每个阶段完成后运行对应测试并提交。

## 阶段 1：分片事实模型

- 新增数据库迁移：generation 分片汇总字段、页面准备信息、`translation_segments` 和活动翻译图层。
- 扩展领域 DTO、缓存路径和仓储事务。
- 保持旧页面级任务、译图和接口可读。
- 增加迁移、汇总、恢复和图层优先级测试。

## 阶段 2：规划与 OCR 检查点

- 新增 `SegmentPlanner`，按顺序缓存全话源图并原子写入确定性分片计划。
- 分离无重叠显示边界与带上下文的 OCR 边界。
- 固定发送 `useOcrForImageBlock: true`。
- OCR 客户端暴露提交、轮询和结果解析边界，以便保存并恢复 `jobId`。
- 增加图片块参数、切分连续性和 OCR 恢复测试。

## 阶段 3：严格串行执行器

- 新增 `SegmentRunner`，单片执行 OCR、翻译、渲染、缓存和原子发布。
- 重构 `TranslationManager`：准备、串行调度、当前分片后暂停、启动恢复、单片失败继续。
- 实现按失败阶段复用检查点的单片重试与整话重新翻译。
- 增加顺序、进度、暂停、失败、重启及重译测试。

## 阶段 4：API 与媒体兼容

- 扩展任务响应的分片进度、分片状态和有效翻译图层。
- 新增单片重试和不可变译片媒体接口。
- manifest 返回源页图层；旧整页译图和页面级重试接口继续工作。
- 增加 API、缓存版本和鉴权边界测试。

## 阶段 5：阅读器 UI

- 拆分顶部控制栏、底部胶囊、目录抽屉、阅读设置和源页翻译图层组件。
- 实现首次显示、3 秒自动隐藏、滚动隐藏、点击切换及面板打开时保持显示。
- 顶部按分片显示翻译进度；底部按源页显示阅读进度。
- 底部按钮固定为上一话、下一话、目录、阅读设置。
- 实现逐片覆盖、关闭立即原图、单片失败重试，并移除“译图”角标。

## 阶段 6：缓存、设置与文档

- 将源图、OCR 裁片、OCR 响应、文字块、译文和译片纳入现有 5GB 章节 LRU。
- 更新设置说明：OCR 分片固定单并发，翻译并发只用于当前片内部。
- 更新 README 和部署/行为说明。

## 阶段 7：完整验证与收尾

- 运行 pytest、Ruff、前端格式检查、lint、TypeScript 和生产构建。
- 用现有真实章节数据验证迁移、分片总数、逐片状态和服务重启。
- 检查所有提交作者与工作区状态，提交剩余改动。
- 停止 ComicLens 服务及视觉示例服务，并确认端口不再监听。
