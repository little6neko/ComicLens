# ComicLens 详情页章节正逆序实施计划

## 目标

按已确认的设计，将漫画详情页“章节”标题右侧的静态话数替换为参考 jm-boom 的圆角排序按钮，并允许在最新话优先与最早话优先之间切换。

## 阶段 1：详情页状态与派生列表

- 在漫画详情页增加默认启用的降序状态。
- 保留 API 返回的原始章节数组，不执行原地反转。
- 降序时直接使用原始稳定顺序；正序时渲染原始数组的反转副本。
- 继续阅读目标继续接收原始漫画详情，不与临时显示顺序耦合。

## 阶段 2：排序按钮

- 将章节标题右侧的静态“X 话”改为现有 `Button` 的 `outline`、`sm` 组合。
- 按钮保留“X 话”文字，并根据当前方向显示 Lucide 的窄宽升序或降序图标。
- 点击切换排序方向；为两种状态提供明确的 `aria-label` 和悬停提示。
- 保留现有章节行、已读灰色、更新时间与阅读链接样式。

## 阶段 3：验证与交付

- 静态检查列表渲染使用派生章节数组，阅读目标仍使用原始详情。
- 运行前端格式化、格式检查、Lint、TypeScript 检查和生产构建。
- 检查 Git 差异和提交者信息后提交实现。
- 重启 `comiclens.service`，确认服务存活并监听 `0.0.0.0:8233`。
