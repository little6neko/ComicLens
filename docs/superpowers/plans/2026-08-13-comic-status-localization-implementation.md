# ComicLens 漫画状态中文化实施计划

## 目标

按已确认的规格，将详情页已知 Manga18fx 状态转换为“连载”或“完结”，同时让未知非空状态安全回退到上游原文。

## 阶段 1：独立状态转换

- 在漫画详情功能目录新增无副作用的状态显示函数。
- 对输入执行首尾空白清理，并以不区分大小写的值匹配 `Ongoing` 和 `Completed`。
- 已知值分别返回“连载”和“完结”；未知非空值返回清理后的原文；空值返回 `null`。
- 不改变后端状态解析、领域类型或 API 响应。

## 阶段 2：详情页接入

- 漫画详情页通过独立函数计算显示状态。
- 仅在转换结果非空时渲染现有状态位置与分隔符。
- 不改动作品类型、评分、发行日期、章节或其他详情布局。

## 阶段 3：验证与交付

- 定向验证 `Ongoing`、`OnGoing`、大小写及空白变体均显示“连载”。
- 定向验证 `Completed` 的大小写及空白变体均显示“完结”。
- 定向验证未知值保留清理后的原文，空值不显示。
- 运行前端格式化、格式检查、Lint、TypeScript 与生产构建。
- 检查差异与提交者信息后提交代码。
- 重启 `comiclens.service`，确认监听 `0.0.0.0:8233` 且详情 API 与页面正常响应。
