# ComicLens 详情页与阅读器细节调整实施计划

## 目标

按已确认的规格补充 Release、统一已读灰色、调整继续阅读文案，并仅移除阅读器的 3 秒自动隐藏计时。

## 阶段 1：Release 数据链路

- 为后端 `ComicDetail` 和前端 `ComicDetail` 增加可空的 `releaseLabel`。
- 从 Manga18fx 现有详情元数据映射读取 `Release` 原始值。
- 更新来源 fixture、来源解析测试和目录 API 测试。
- 在详情页作品信息区按“发行日期 {值}”展示，空值不渲染。

## 阶段 2：继续阅读文案

- 新增独立的纯前端阅读目标辅助模块。
- 多话历史章节优先从 `Chapter`/`Ch.` 标记提取实际整数或小数话数。
- 无法提取时按最旧到最新的位置回退为稳定序号。
- 单话历史保持“继续阅读”，无有效历史保持“开始阅读”。
- 详情页改用统一辅助函数，不改变目标章节和页码。

## 阶段 3：已读灰色

- 详情页移除已读勾号，整行使用主题 `muted` 语义色和清晰 hover/focus 状态。
- 阅读器查询现有精确已读章节集合，并传给章节目录。
- 阅读器目录移除当前章节勾号；当前高亮优先，已读非当前章节使用可读的深色灰度。
- 保留现有已读写入 mutation 和查询缓存更新。

## 阶段 4：阅读器控制细节

- 从 `useReaderChrome` 删除 3 秒常量、计时器及调度逻辑。
- 保留首次显示、章节切换显示、点击切换、滚动/触摸隐藏、键盘/鼠标显示和面板强制显示。
- 将底部第三个按钮从“目录”改为“章节目录”，不改顺序、图标或布局。

## 阶段 5：验证与交付

- 运行 Ruff、完整 pytest、前端格式检查、lint、TypeScript 和生产构建。
- 对真实 Manga18fx 详情 API 验证 `releaseLabel`。
- 静态检查详情页和章节目录不再包含用于已读/当前章节的勾号。
- 静态检查阅读器显隐 hook 不再包含定时器或 3000ms 常量。
- 提交实现并重启 `comiclens.service`，确认监听 `0.0.0.0:8233`。
