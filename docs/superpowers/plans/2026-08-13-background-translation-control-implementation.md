# 后台 OCR 翻译进度与强制停止实施计划

1. 扩展翻译领域模型，增加精简的后台任务摘要与强停操作响应。
2. 在 Repository 中实现活动任务查询、历史标题快照合并，以及强停后的事务化可恢复状态回滚。
3. 在 TranslationManager 中按话取消并等待 worker，串行完成状态回滚、缓存活动标记清理和幂等处理。
4. 新增后台任务列表与按话强停 API，并扩展前端 API 类型、调用方法和查询键。
5. 在设置页标题下增加每秒刷新、多卡片后台任务区域，显示阶段、分片进度、失败数和逐卡强停确认。
6. 将“长图高级设置”改名为“OCR 长图高级设置”。
7. 增加 Repository、Manager 和 API 回归测试，覆盖检查点保留、恢复续跑、强停隔离和标题兜底。
8. 运行 Python 测试与静态检查、前端格式/Lint/TypeScript/生产构建。
9. 重启 ComicLens，通过真实任务或受控测试数据验证设置页卡片和强停交互。
10. 提交实现并推送 SSH 远端 `main`。
