# 设置页版本区块与后台翻译任务列表实施计划

## 目标

按已确认设计，在设置页顶部显示 `ComicLens v0.0.1` 版本区块，并将后台 OCR 翻译任务从独立大卡片改为统一紧凑列表。保持现有 API、轮询、停止任务和错误处理逻辑不变。

## 阶段 1：增加前端版本信息

涉及文件：

- 新增 `web/src/lib/version.ts`
- 修改 `web/src/routes/_app/settings.tsx`

实施内容：

- 在独立模块导出版本常量 `0.0.1`，不接入服务器设置或数据库。
- 在设置页引入 `PackageIcon`、确认图标和版本常量。
- 在设置表单最前面新增“版本”设置区块，复用现有 `SettingsSection` 外观。
- 区块内容横跨两列：左侧显示“ComicLens”和“当前应用版本”，右侧显示描边圆形胶囊 `v0.0.1`。
- 保持安全警告和 `BackgroundTranslationTasks` 位于版本区块上方，因此活动翻译进度拥有更高显示优先级。

验证：

- 没有后台任务时，版本区块是安全警告后的第一个设置卡片。
- 版本徽章不可点击，不参与底部“保存全部设置”。
- 深色和浅色主题均可读。

## 阶段 2：重构后台任务为紧凑列表

涉及文件：

- 修改 `web/src/features/settings/background-translation-tasks.tsx`

实施内容：

- 删除不再使用的 `BookOpenIcon` 和 `buttonVariants`。
- 将任务容器从响应式两列网格改为单个 `rounded-3xl` 卡片，任务行之间使用分隔线。
- 将 `BackgroundTaskCard` 改为语义明确的任务行组件；无论任务数量多少都使用同一结构。
- 保留漫画详情链接和章节阅读器链接，删除重复的“查看章节”按钮。
- 桌面端在任务行顶部对齐标题、阶段和停止按钮，进度条及数值位于下方。
- 手机端允许顶部信息换行，停止按钮、阶段、失败数和源图缓存数始终可见。
- 保留未知分片时的脉冲进度、已知分片时的百分比、源图缓存统计和失败统计。
- 保留停止确认文案、mutation 状态、查询缓存更新、轮询和错误提示，不改变 API 数据流。

验证：

- 1 个和 4 个任务使用相同列表结构，任务变化不会切换布局。
- 漫画名和章节名分别指向原有详情页与阅读器地址。
- 停止按钮在处理中禁用并显示加载图标。
- `stopping` 阶段、失败数量和接口读取失败仍使用现有语义颜色。

## 阶段 3：静态检查与浏览器回归

执行：

- `npm run fmt`
- `npm run fmt:check`
- `npm run lint`
- `npm run build`
- `.venv/bin/pytest -q`
- `git diff --check`

浏览器验证：

- 使用临时数据目录启动仅监听回环地址的隔离服务。
- 通过浏览器测试环境模拟 4 个不同阶段的后台任务，不修改正式数据库。
- 检查宽屏下任务行的标题、阶段、进度和停止按钮对齐。
- 检查手机宽度下内容自然换行且没有横向溢出。
- 检查后台任务区域位于版本区块上方，两者均处于普通文档流且不重叠。
- 检查无任务状态下后台区域不占空间。
- 检查浅色、深色主题以及版本徽章可读性。
- 验证完成后关闭隔离服务和调试浏览器，不启动正式 `comiclens.service`。
